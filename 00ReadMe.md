## Structure
### Types of Notes
I've created four core tags to classify each note in order to capture properties and create the knowledge map. These general categories are high level groupings.
- Topic - Captures information about a particular note
- Idea -  Captures *my ideas* about a topic or event
- Source - A source or paper
### other link types
- Topic - Any note created can become a *topic* if linked by another note
- Subset - I use this property to link between several ideas in a note
- Alias - Used to created multiple names for a note

As I am trying to create this structured site for the first time, I am not adding information about authors or other tags that maybe added at a future time
