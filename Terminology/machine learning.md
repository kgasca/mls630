# machine learning

## Definition
[Source](https://www.ibm.com/think/topics/machine-learning)
>Machine learning is the subset of artificial intelligence (AI) focused on algorithms that can “learn” the patterns of training data and, subsequently, make accurate _inferences_ about new data. This pattern recognition ability enables machine learning models to make decisions or predictions without explicit, hard-coded instructions. (Bergman, n.d.)
